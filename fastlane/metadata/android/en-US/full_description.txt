Quicklog is a deliberately tiny note taker. You open it, you type, you press
"Log text", and the note lands as a plain Markdown file named
ql-YYMMDD-HHMMSS.md. There is no account, no telemetry and no database -- by
default the files are yours, sitting in a folder you choose.

Quicklog does not synchronise anything by itself. The default mode is local
only. An optional S3 mode (Preferences) can write the same Markdown notes to a
user-configured S3-compatible endpoint; access keys stay on the device and are
never uploaded elsewhere. If you want local notes on your computer or another
phone, run a separate sync app -- Syncthing is the one this was written for --
and point it at the folder Quicklog writes to. Because the notes are ordinary
Markdown files (or ordinary S3 objects with the same names), any sync, backup
or file manager app works; there is nothing Quicklog-specific about them.

Features:

* Single-screen editor with a character counter.
* Every press of "Log text" writes a new timestamped Markdown file (or S3
  object, if you enable S3 mode).
* Entry browser listing previous notes, newest first, with a reader view.
* Edit a past entry in place: the note keeps its original filename, timestamp
  and position in the list. Save and Revert stay disabled until something
  actually changes, and leaving with unsaved changes asks first.
* Delete an entry from the list or from the reader, always behind a
  full-screen confirmation showing the filename, timestamp and a preview.
  Deletion is permanent -- there is no trash folder.
* "Share to Quicklog" from any app that can share text. Depending on your
  preference the text is either prefilled in the editor or logged straight
  away.
* Choose a local folder with Android's folder picker, or type a directory path;
  optional S3 endpoint, region, bucket and keys.

Storage and permissions:

By default Quicklog writes to its own app-specific external directory,
/storage/emulated/0/Android/data/org.buetow.quicklog/files/, which needs no
storage permission at all. Point your sync app at that folder and you are
done.

For an existing notes vault, select it through the Android folder picker in
Preferences. Quicklog keeps that folder's scoped grant; no broad storage
permission is needed. If access is revoked, select the folder again in
Preferences. Typed directory paths are still available. A typed path into
shared storage may require "All files access" (MANAGE_EXTERNAL_STORAGE) on
Android 11+, or Storage permission on Android 7-10. GrapheneOS users can also
use Storage Scopes for typed paths. Switching folders does not move notes.
On Android 11+, writing new notes may work while notes created outside Quicklog
remain hidden. Use the folder picker for an existing vault.
Settings exports cannot transfer an Android folder grant; select the folder
again after importing settings.

Network access is only used if you turn on S3 mode and configure an endpoint.
Credentials never leave SharedPreferences on the device. "Test connection"
probes without saving; only Save persists the keys.
